# Hex
 
Игра в гекс. Есть выбор режима (лёгкий против компьютера, сложный против компьютера, и с двумя игроками), выбор цвета, кто первый ходит, выбор размера поля.

После этого начинается игра: каждый игрок по очереди закрашивает в свой цвет один из шестиугольников, побеждает тот, у кого будет путь от одной "своей" стороны (отмеченной его цветом) к противоположной.

В лёгком режиме компьютер ходит случайным образом.
